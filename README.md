# 📱 Phonebook

A responsive contact management application built with **React and TypeScript**.

The application allows users to register, log in, manage their contacts, search through the contact list, and perform CRUD operations. The project was developed to practice working with React, TypeScript, Redux Toolkit, REST APIs, authentication, form validation, and persistent application state.

## 🏗️ Project Structure

The application is organized using reusable React components and separated application logic.

The main parts of the application include:

- Authentication pages
- Contact management
- Contact list
- Contact forms
- Search functionality
- Protected routes
- Redux store
- API services
- Reusable UI components

## 🔐 Authentication

The application uses authentication to provide users with access to their personal contacts.

Protected routes prevent unauthorized users from accessing the contact management functionality.

Authentication state is persisted using **Redux Persist**, allowing the application to maintain the user's state between browser sessions.

## 📡 API Integration

The application communicates with a backend through a **REST API**.

**Axios** is used to handle HTTP requests, including:

- User registration
- User login
- User logout
- Fetching contacts
- Creating contacts
- Updating contacts
- Deleting contacts

## 📋 Contact Management

Users can manage their contacts through standard CRUD operations:

**Create → Read → Update → Delete**

The contact list can also be filtered using the search functionality.

## 📝 Forms & Validation

Forms are implemented using **Formik** and validated with **Yup**.

Validation helps ensure that users provide valid information before submitting authentication or contact forms.

## 🔔 Notifications

**React Hot Toast** is used to provide feedback to users after important actions, such as successful operations or API errors.

## 📱 Responsive Design

The interface is designed to work across different screen sizes, including desktop, tablet, and mobile devices.
